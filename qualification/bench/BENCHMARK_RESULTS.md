## Limitations

- 12 runs per profile is a small sample; intervals are wide by design and a finite sample cannot establish zero degradation.
- Latency is end-to-end CLI wall time (startup + inference + tools); provider-side variance dominates.
- Native token usage and billing are not observable here.
- Cold/warm cache is not controlled: every run is a fresh session (cold prompt cache) for all profiles alike.
- Tasks are short; long-running, interruption-heavy work is covered by the live matrix, not by this benchmark.
